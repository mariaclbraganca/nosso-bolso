\# SKILLS.md — Matriz de Competências Técnicas



\## Skill: Database Architect (Supabase/PostgreSQL)

\- Implementação de Triggers para automação de saldo (`fn\_atualiza\_saldo\_envelope`).

\- Configuração de Row Level Security (RLS) para acesso anônimo seguro.

\- Gestão de Realtime Replication para sincronização entre dispositivos.



\## Skill: Backend Engineer (FastAPI/Python)

\- Criação de modelos Pydantic com validação rigorosa (`valor > 0`, tipos permitidos).

\- Desenvolvimento de rotas RESTful para CRUD de envelopes, transações e gastos fixos.

\- Integração com `supabase-py` para operações de banco e filtros de dashboard.



\## Skill: Frontend Developer (Flutter/Riverpod)

\- Gerenciamento de estado reativo com `StreamProvider` e `StateProvider`.

\- Construção de UI fiel ao protótipo HTML usando `CustomScrollView` e `SliverGrid`.

\- Implementação de componentes complexos como o `SpeedDialFAB` animado.



\## Skill: QA \& Auditoria

\- Garantia de que o código respeita o limite de 200 linhas por arquivo.

\- Testes de estorno: garantir que deletar uma transação restaura o saldo via trigger.
